04 / 06

Hogwarts Hidden Library

C++ · OOP · STL · File I/O

A terminal-based library management system built in C++ using object-oriented principles. It supports full CRUD operations — adding and removing books, registering and removing users, and managing borrow/return workflows with real-time availability tracking.

Implemented data integrity constraints: Removing a user that is currently borrowing a book is not allowed, borrowing a book that hasn't been returned is not allowed, and deleting an unreturned book is also not allowed. Data persists to file storage, and the CLI uses ANSI color-coding for readability.
